# lockUp pay

Marketing site for lockUp pay, the enterprise smartphone-financing telematics platform for mobile retailers in India. The site has two pages: the landing page and the terms of use. It does not include a device client, an MDM agent, or any control that locks or releases a handset.

## Run locally

```bash
npm install
npm run dev
```

The dev server listens on [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Pages

- `/` — product landing page
- `/terms` — terms, platform policy, clause search, and merchant acknowledgment

## Production build

```bash
npm run build
npm start
```
